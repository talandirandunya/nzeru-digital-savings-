## Part 1: Backend Deployment on Railway

### Prerequisites
- Railway account with PostgreSQL database
- Git repository connected to Railway
- Django admin panel access

### Step 1: Update Environment Variables in Railway Dashboard

Navigate to your Railway project → Variables and add/update:

```
DJANGO_DEBUG=False
DJANGO_SECRET_KEY=<generate-new-key>
DATABASE_URL=<auto-generated-by-railway>
ALLOWED_HOSTS=savingsutl-production-bf7e.up.railway.app,.railway.app
DJANGO_SUPERUSER_USERNAME=admin
DJANGO_SUPERUSER_EMAIL=admin@yourdomain.com
DJANGO_SUPERUSER_PASSWORD=<strong-password>
PORT=8000
```

**Generate a new SECRET_KEY:**
```bash
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

### Step 2: Deploy Updated Files

Commit and push these files to your main branch:

```bash
cd backend
git add entrypoint.sh config/settings.py api/views.py
git commit -m "fix: resolve container restarts, CORS issues, pagination warnings"
git push origin main
```

Railway will automatically trigger a deployment.

### Step 3: Monitor Deployment

1. Go to Railway Dashboard → Deployments
2. Watch the container logs for:
   ```
   ==> Running migrations...
   ==> Creating superuser (if not exists)...
   SUCCESS: Superuser "admin" created.
   ==> Collecting static files...
   ==> Starting Gunicorn on port 8000...
   ```
3. Confirm no restart loops occur (check Deployments → Recent Builds)

### Step 4: Verify Backend Health

Test the API endpoints:

```bash
# Check if server is running
curl https://savingsutl-production-bf7e.up.railway.app/api/health/

# Test login endpoint
curl -X POST https://savingsutl-production-bf7e.up.railway.app/api/auth/login/ \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser","password":"TestPass123!"}'

# Get current user (with token)
curl https://savingsutl-production-bf7e.up.railway.app/api/auth/me/ \
  -H "Authorization: Bearer <access_token>"
```

## Part 2: Frontend Build & Deployment

### Prerequisites
- Flutter SDK installed
- Web dependencies up to date
- All updated files in place

### Step 1: Update pubspec.yaml (if needed)

Ensure these dependencies are present:

```yaml
dependencies:
  flutter:
    sdk: flutter
  provider: ^6.0.0
  http: ^1.0.0
  google_fonts: ^5.0.0
  intl: ^0.18.0
  fl_chart: ^0.62.0  # Not strictly needed for candlesticks, but good to have
  
dev_dependencies:
  flutter_test:
    sdk: flutter
```

Run: `flutter pub get`

### Step 2: Test Locally

```bash
# Clean build
flutter clean

# Get dependencies
flutter pub get

# Run on web (development)
flutter run -d chrome

# Or build web
flutter build web --release
```

### Step 3: Verify New Dashboard

In your browser:
1. Register a new account
2. Log in
3. Verify Dashboard displays:
   - Total savings with MK format (e.g., "MK 1,250,000.00")
   - Candlestick chart with 7-day deposit data
   - Quick action buttons
   - Recent transactions with proper currency formatting

### Step 4: Deploy to Netlify

#### Option A: Using Netlify CLI

```bash
# Install Netlify CLI
npm install -g netlify-cli

# Build web version
flutter build web --release

# Deploy
netlify deploy --prod --dir=build/web
```

#### Option B: Using GitHub Actions

Create `.github/workflows/flutter-web.yml`:

```yaml
name: Flutter Web Build & Deploy

on:
  push:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.x.x'
      
      - run: flutter pub get
      
      - run: flutter build web --release
      
      - uses: netlify/actions/cli@master
        with:
          args: deploy --prod --dir=build/web
        env:
          NETLIFY_AUTH_TOKEN: ${{ secrets.NETLIFY_AUTH_TOKEN }}
          NETLIFY_SITE_ID: ${{ secrets.NETLIFY_SITE_ID }}
```

### Step 5: Update CORS Settings

After getting your Netlify URL, update Railway environment:

```
CORS_ALLOWED_ORIGINS=
https://savingsutl-production-bf7e.up.railway.app,
  https://your-netlify-site.netlify.app,
  http://localhost:3000,
  http://localhost:8081
```

## Part 4: Troubleshooting

### Backend Issues

#### Container keeps restarting
```bash
# Check Railway logs
# Look for: "CommandError: That username is already taken"
# Solution: Already fixed in updated entrypoint.sh
```

#### CORS errors on frontend
```bash
# Error: "Access to XMLHttpRequest blocked by CORS policy"
# 1. Verify origin is in CORS_ALLOWED_ORIGINS
# 2. Check CORS_ALLOW_CREDENTIALS is True
# 3. Ensure Authorization header is included
```

#### Database connection errors
```bash
# Check DATABASE_URL is set correctly
# Verify PostgreSQL is running on Railway
# Check if migrations ran successfully in logs
```

### Frontend Issues

#### Candlestick chart not showing
```dart
// Verify candles list is not empty
if (candles.isEmpty) {
  return Text('No data available');
}
```

#### Currency formatting showing scientific notation
```dart
// Use CurrencyFormatter instead of toStringAsFixed
Text(CurrencyFormatter.formatMK(amount))
// Instead of: Text('$amount')
```

#### Responsive layout broken on mobile
```dart
// Ensure SingleChildScrollView wraps Column
// Use Expanded/Flexible for dynamic sizing
// Test with different screen sizes in DevTools
```

#### Provider not updating
```dart
// Verify context.read() and context.watch() usage
// Check if notifyListeners() is called in provider
// Look for exceptions in console output
```

## Part 5: Performance Optimization

### Backend Optimization

1. **Database Queries**
   ```python
   # Use select_related for foreign keys
   queryset = Loan.objects.select_related('user').all()
   
   # Use prefetch_related for reverse relations
   queryset = User.objects.prefetch_related('loans').all()
   
   # Limit fields returned
   queryset = User.objects.only('id', 'username', 'email')
   ```

2. **Caching**
   ```python
   from django.views.decorators.cache import cache_page
   
   @cache_page(60 * 5)  # Cache for 5 minutes
   def get_financial_report(request):
       ...
   ```

3. **Pagination**
   ```python
   # Already configured in settings.py
   REST_FRAMEWORK = {
       'DEFAULT_PAGINATION_CLASS': 'rest_framework.pagination.PageNumberPagination',
       'PAGE_SIZE': 20,
   }
   ```

### Frontend Optimization

1. **Image Optimization**
   ```dart
   Image.asset(
     'assets/logo.png',
     cacheHeight: 200,
     cacheWidth: 200,
   )
   ```

2. **Lazy Loading**
   ```dart
   ListView.builder(
     itemBuilder: (context, index) => TransactionTile(...),
   )
   ```

3. **Const Widgets**
   ```dart
   const SizedBox(height: 20)  // Reused constant
   ```

### Common Patterns

**Error Handling in API Service:**
```dart
try {
  final response = await http.post(...)
      .timeout(const Duration(seconds: 30));
  return _handleResponse(response);
} on SocketException catch (e) {
  throw Exception('Network error: ${e.message}');
} on TimeoutException {
  throw Exception('Request timeout');
} catch (e) {
  throw Exception('Unknown error: $e');
}
```

**Currency Formatting:**
```dart
// Always use CurrencyFormatter for consistency
Text(CurrencyFormatter.formatMK(amount))

// Different formats:
CurrencyFormatter.formatMK(1250000)        // MK 1,250,000.00
CurrencyFormatter.formatCompact(1250000)   // MK1.3M
CurrencyFormatter.formatPercentage(12.5)   // +12.5%
```
